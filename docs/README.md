# 📚 Documentation

## 📖 Overview

This folder contains all developer‑facing documentation to help anyone understand, set up, and work on the **Intelligent Commerce Engine** project.

- **Minute‑to‑minute workflow** – what to do from cloning the repo to running the full stack.
- **Architecture diagram** – high‑level system view (frontend, backend, Gemini AI, Firebase).
- **API reference** – all REST endpoints exposed by the backend with request/response shapes.
- **Data schemas** – description of the core entities (Product, PricingSuggestion, ReorderSuggestion, etc.).
- **Development guide** – tooling, environment variables, testing, and deployment.

All files are written in Markdown and placed under `docs/` in the repository root.

- **Workflow** – detailed minute‑to‑minute guide (`docs/workflow.md`)
- **API Reference** – full endpoint list (`docs/api.md`)
- **Data Schemas** – entity definitions (`docs/schemas.md`)
- **Architecture Diagram** – system overview (`docs/architecture.md`)
